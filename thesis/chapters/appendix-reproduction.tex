\chapter{Reproducing the Results}\label{app:reproduction}
% The commands and scripts that regenerate every number in Chapter~\ref{chap:evaluation}.

This appendix lists what is needed to regenerate the tables of \Cref{chap:evaluation}. All commands are in the directory
\texttt{graal-native} of the tool's repository; the builder is the Graal fork, which the repository contains as a submodule.

\section{The Headline Tables from One Commit}

The script \texttt{reproduce.sh} produces the tables of \Cref{sec:eval-gain,sec:eval-cost} and of the lock shapes in
\Cref{sec:eval-concurrency} in one run. It refuses to start unless the tool and the fork are exactly a commit (no changed
tracked files, no untracked files) and the builder is not older than the fork's sources. With \texttt{ALLOW\_DIRTY=1} it runs
for testing and marks the results \texttt{NOT-REPRODUCIBLE}. The procedure of the clean run of 29 October, on a machine
where nothing else runs, was:

\begin{lstlisting}[language=bash]
# on the development machine, from clean, committed checkouts of the tool and of the fork:
graal-native/sync-pontos.sh        # copies both trees to the server and stamps them with their commits

# on the server:
export JAVA_HOME=$HOME/.mx/jdks/labsjdk-ce-latest-jvmci-25.4-b23_amd64
export PATH=$JAVA_HOME/bin:$HOME/mx:$HOME/.local/bin:$PATH
cd ~/graal/substratevm && mx build # the builder must be newer than the sources
cd ~/explicit-effects/graal-native && ./reproduce.sh
\end{lstlisting}

The results are written to \texttt{out/reproduction/<UTC time>-<commit>/}: \texttt{provenance.txt} (which code), one file per
stage, and \texttt{SUMMARY.txt}. \Cref{tab:app-stages} lists the stages. The default stages took 74 minutes on 29 October.

\section{Other Measurements}

The results that \texttt{reproduce.sh} does not regenerate have their own scripts, listed in \Cref{tab:app-scripts}.
The first four stages of the clean run reproduced the loads of \Cref{tab:eval-loads} to the unit and the lock shapes of
\Cref{tab:eval-shapes} to the second decimal; the matrix, javac, PetClinic, and the Barista applications were not part of it.
